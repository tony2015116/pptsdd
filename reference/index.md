# Package index

## HTTP downloads

Log in and request the CSV report directly, without a browser. Start
here when the report you need is the default CSV export.

- [`get_csv()`](https://tony2015116.github.io/tidypptsdd/reference/get_csv.md)
  : Direct web scraping CSVs
- [`get_csv_auto()`](https://tony2015116.github.io/tidypptsdd/reference/get_csv_auto.md)
  : Direct web scraping CSVs

## Browser downloads

Choose a CSV report from the website menu in Chrome or Edge. The
WebDriver service is managed by wdauto.

- [`connect_to_browser()`](https://tony2015116.github.io/tidypptsdd/reference/connect_to_browser.md)
  : Start a browser WebDriver service
- [`download_csv_auto()`](https://tony2015116.github.io/tidypptsdd/reference/download_csv_auto.md)
  : Automatically download CSVs
- [`disconnect_from_browser()`](https://tony2015116.github.io/tidypptsdd/reference/disconnect_from_browser.md)
  : Reset selenium webdriver service

## Scheduled downloads

Register a Windows Task Scheduler task that downloads the previous day’s
reports.

- [`get_csv_schedule()`](https://tony2015116.github.io/tidypptsdd/reference/get_csv_schedule.md)
  : Schedule automatic downloads of CSVs
- [`download_csv_schedule()`](https://tony2015116.github.io/tidypptsdd/reference/download_csv_schedule.md)
  : Schedule automatic downloads of CSVs
